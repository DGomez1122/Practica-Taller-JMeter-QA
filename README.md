# Taller Práctico Apache JMeter

Proyecto desarrollado para la práctica de pruebas de rendimiento utilizando Apache JMeter y la API Swagger Petstore.

## Contenido

* Pruebas de Carga (Load Test)
* Pruebas de Estrés (Stress Test)
* Pruebas de Pico (Spike Test)
* Pruebas de Resistencia (Soak Test)
* Implementación de Aserciones
* Logs y Depuración
* Evidencia de Fallos
* Análisis de Resultados

## Herramientas utilizadas

* Apache JMeter 5.6.3
* Swagger Petstore API
* GitHub
